## 硬规则

- 强制风险项；**观察 ≠ 推荐购买**
- **不发帖、不试单、不对 bot 发交易/下单消息**；不接 VIP 转发
- 商品价目只来自：**公开群/频道帖**、**公开 bot/频道页 og 文案**、用户提供的公开截图（须补可核 msgid 或标明「截图待补出处」）
- 禁止写购买步骤、支付地址教程、盗号/换绑操作

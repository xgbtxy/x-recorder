# TG 群组 + Bot 目录

用途：维护可查询的 **Telegram 群组档案** 与 **群内店铺 bot** 对照（不限 elitemethodchat）。专员主写；需登录才能看的群由老大用阿言 Telegram Web **只读**协采。

| 子目录 | 写什么 |
|--------|--------|
| `groups/` | 群/超级群档案：**群用户名必填**（`@name` 或 `t.me/name`）；访问方式；群内 bot 表 |
| `bots/` | 从这些群挖到的店铺 bot（价目店可交叉 `../bots/em-shop/`） |

入库：`records/other/tg-catalog/`；README 索引可用 `[低价·群]` / `[低价·bot]`。

## 专员怎么干（阿言 2026-09-26）

1. **主动找新群**（公开预览优先）：号铺/订阅店交流群、价目店挂群、土豆聚合延伸群等。
2. 每条群档必须写清 **群用户名**（没有公开 username 的记 invite 形态并标「无公开用户名」）。
3. 进群只读翻帖 → 把店铺 bot 写入本目录 `bots/` 或 `../bots/em-shop/`（有公开多品价目优先 em-shop）。
4. 需登录/私密群：先提案给老大（链接 + 为何值得），**不要**自己试登录阿言账号以外的方式。
5. 交审：私聊老大；未写 `records/`、未 push。

## 硬规则

- **只读**：不发帖、不试单、不对 bot 下单、不接 VIP 转发
- 强制风险；观察 ≠ 推荐
- 出处优先可点开 msgid；无私链时标明「登录窗可见 / msgid 待补」
- 专员禁止直写 `records/`、禁止 push

模板：`groups/TEMPLATE.md`；价目店可复用 `../bots/em-shop/TEMPLATE.md`。

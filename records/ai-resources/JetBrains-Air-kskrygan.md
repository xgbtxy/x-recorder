## 关键点

- 宣布 **JetBrains Air**：把 IDE、agent、团队协作与治理收成一套「product system」，面向个人开发者 / TL / 工程负责人。
- 口径：开放、可换 LLM 与 harness；承接此前 JetBrains Central / CLI、共享上下文、云 agent、自动化与成本治理等实验。
- 可动手入口：公告短链 https://jb.gg/air-announce → 博文 https://blog.jetbrains.com/blog/2026/09/22/introducing-jetbrains-air/ ；产品页 https://www.jetbrains.com/air/ ；相关 coding agent 见 Junie https://junie.jetbrains.com/ 。
- 相对已入库 observability MCP 线：这是 IDE/组织侧 agent 工作台，不是监控厂商 MCP。

## 价值判断

- 为什么值得记：主流 IDE 厂商把 agentic 开发抬到「组织系统」层，可对照 Cursor / Zed Delta 等。
- 风险 / 待核实：开源/闭源边界、具体可装组件清单与定价仍待核实（公告/产品页 2026-09-26 可开）；勿与已入库 HyperFrames 演示交叉混淆（同账号曾用 HyperFrames 做宣传视频）。

## 关键点

- OpenHands 开源 coding agent 生态的 **Agent Canvas**：浏览器工作台，把一次性对话推进到可审阅、可复用的自动化（dashboard、Git sync、Canvas Apps beta 等）。
- 可动手安装（文档/博文口径）：`npm install -g @openhands/agent-canvas` 后运行 `agent-canvas`（npm 包 `@openhands/agent-canvas` 可查）。
- 支持通过 **ACP（Agent Client Protocol）** 挂接 Claude Code / Codex / Gemini CLI 等外部 harness，也可用 OpenHands 自家 agent；产品页 https://www.openhands.dev/product/canvas 。
- 主仓仍为 https://github.com/OpenHands/OpenHands ；SDK 见 Software Agent SDK。

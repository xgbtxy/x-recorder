## 要点

- Databricks 官方宣布 **Genie One MCP** 一般可用（GA）：ChatGPT、Claude、Cursor 或自定义 Agent 可通过统一接口访问 Genie One 的结构化/非结构化数据、洞察与答案，并落地 Genie Ontology 治理业务语义。
- 亮点口径：跨 Agent 一致业务上下文、带可视化与 Ontology 引用的数据体验、经 Unity Gateway 的集中治理（细粒度策略与审计）。
- 属未入库的企业数据/分析垂直 MCP（非可观测类 ClickStack；非 Neon/Mongo/Prisma）。

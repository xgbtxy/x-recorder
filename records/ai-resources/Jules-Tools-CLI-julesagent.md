## 关键点

- Google Labs 的 Jules（异步 coding agent）推出终端 CLI：Jules Tools。
- 安装：`npm install -g @google/jules`（npm 包 `@google/jules`，描述为 terminal 中的 Jules）。
- 宣称浏览器端能力可在终端完成；产品站 https://jules.google 。
- 适合需要「可装入口」的 coding agent 线：修 bug / 重构等异步任务（具体能力以产品文档为准）。

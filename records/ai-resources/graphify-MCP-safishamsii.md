## 关键点

- Graphify 把代码仓/笔记/PDF/图片等建成可查询知识图谱，面向 Claude Code 等 Agent（`/graphify`）。
- 可动手安装：`pip install graphifyy && graphify install`（PyPI 包名暂为 `graphifyy`，CLI 仍为 `graphify`）；亦支持多平台 skill 安装路径（以 README 为准）。
- 产出 `graphify-out/`（交互图、Obsidian、wiki、graph.json 等）；支持 `query` / `path` / `add`（含 arXiv、X 链接）。
- 帖文提到公开后 MCP 周调用与租户规模等用量数字——一律待核实。

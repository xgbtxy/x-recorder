## 要点

- 官方宣布开放 beta：AI agent 可通过新的 **use_figma** MCP 工具直接在 Figma 画布上设计，并用 **skills** 注入团队决策/意图上下文。
- 可动手入口：开发者文档「Figma MCP server」；另有 MCP 客户端目录 `figma.com/mcp-catalog`（对接 Cursor / Claude / VS Code 等）。
- 与已入库「纯营销图生图」不同：偏设计→代码/画布读写的官方 MCP，可装进现有 coding agent。

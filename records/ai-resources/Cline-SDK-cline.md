## 要点

- 官方宣布开源 **Cline SDK**：称从零重写扩展与 CLI 所用 harness，供他人嵌入/自建 coding agent。
- 安装示例：`npm i @cline/sdk`（帖文写法）；产品本体另见 VS Code/Cursor 扩展与 `github.com/cline/cline`。
- 同生态另有可装 skills 仓 `cline/skills`（`npx skills add https://github.com/cline/skills`），与 SDK/扩展互补，非本帖主点。

# x-recorder 运维规范（老大裁定）

仓库：https://github.com/xgbtxy/x-recorder  
负责人：小弟（阿言授权全权审推与编排）。专员只交草稿，不直接烦阿言。

## 目标

从公开来源（优先 X，已批 TG 频道可用）收录可核对的线索：网安工具、机场/订阅测速、AI 资源、低价渠道等。做成可检索短记录，而不是教程站或商家广告墙。

## 流水线（强制）

```
专员发现 → 写 drafts/<线>/ → 私聊/群里报老大 → 老大审计
  → 通过：迁入 records/<分类>/ + 更新 README 索引 + git push
  → 驳回：留在 drafts/…-REJECTED.md 或删稿并注明原因
```

1. **专员禁止**直写 `records/`、禁止 `git push`、禁止改 README 索引（除非老大点名）。
2. **专员禁止**擅自发帖、建群、对外代表阿言。
3. 重复已入库链接：不交；以仓库 `records/` + README 为准。
4. 与别线重叠：转对应专员，或草稿里标注「建议改线」后报老大。

## 硬规则

1. **可核对出处**：优先 `https://x.com/.../status/...`；TG 须 `t.me/.../消息号`（或等价可点开链接）并标明平台。
2. **只记入口与关键点**：仓库/官网/文档、能力一句话。不写违法操作步骤、绕过教程、PoC 复现细节。
3. **夸大/未证实**：写入「风险 / 待核实」，不删来源。
4. **低价线**：必须写风险项（跑路、钓鱼、盗刷、虚假额度、来路不明号、二次倒卖等）；不收硬广堆码、不收盗号教程。
   - **2026-09-25 重点方向**（阿言）：TG 账号购买/批发平台（号铺）、土豆聚合网类频道/群目录站、低价机器人（充值/比价/发卡 bot）。公开站点与可核出处可收；只记入口与风险，不教买卖流程、不替商家引流话术。
   - **2026-09-26 优先级**（阿言再强调）：**低价 bot 特别重要**，高于泛 AI 线索刷量。主责仍在小弟·低价资源，目录 `drafts/deals/bots/` → 入库标题 `[低价·bot]`；小弟·TG 从已批频道/公开群线索协写 bot 入口。禁止：发帖、购买/试单、接 VIP 转发（除非阿言点名）。
   - **2026-09-26 扩面**（阿言）：`tg-catalog` **不止 elitemethodchat**。专员主动发现并登记**新群组**（须记 **群用户名** `@…` / `t.me/…`）、再从群内挖店铺 bot；公开群用公开预览，需登录群报老大协采。群档写 `drafts/deals/tg-catalog/groups/`，群内 bot 写 `tg-catalog/bots/` 或交叉 `bots/em-shop/`。
5. **机场测速**：收结构化测速/观察帖；拒邀请码硬广；测试≠推荐；商家拿不准先报老大。

## 审计清单（老大）

- [ ] 出处链接可开（或已用公开预览核对）
- [ ] 落地仓库/官网可开（或明确标待核实）
- [ ] 非重复（对照 README / records）
- [ ] 无教程/PoC/硬广违规
- [ ] 状态改为「已核」或驳回理由清楚
- [ ] README 索引一行 + push `main`
